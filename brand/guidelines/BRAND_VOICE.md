# LINCE — Guía de Voz y Comunicación de Marca

**Versión 2.0.0** | Brand Voice & Tone Guidelines

---

## 1. Personalidad de Marca

LINCE es como **ese amigo brillante que trabaja en IA** y consigue que entiendas conceptos complejos haciéndolos parecer emocionantes y accesibles, nunca condescendiente, siempre motivador.

### 1.1 Los 4 Rasgos de Personalidad

| Rasgo | Qué significa | Cómo se manifiesta |
|---|---|---|
| **Empoderador** | LINCE cree en cada usuario | Frases que celebran el progreso, nunca el fracaso |
| **Directo** | Sin tecnicismos innecesarios | Explicaciones claras, ejemplos concretos |
| **Entusiasta** | El aprendizaje es una aventura | Energía positiva, celebración de logros |
| **Confiable** | Información precisa y honesta | Datos verificados, promesas cumplibles |

## 2. Tono por Contexto

### 2.1 Onboarding y Bienvenida

**Tono**: Cálido, emocionante, orientador

```
✅ "¡Bienvenido/a a LINCE! Tu aventura en IA comienza ahora. 
   Elige tu avatar y empieza a ganar XP. 🚀"

❌ "Por favor complete el proceso de registro para acceder 
   a las funcionalidades de la plataforma."
```

### 2.2 Instrucciones y Ayuda

**Tono**: Claro, paciente, paso a paso

```
✅ "Pulsa el botón azul para enviar tu prompt. 
   Cuanto más específico sea, mejores resultados obtendrás."

❌ "El sistema procesará la entrada del usuario mediante 
   el modelo de lenguaje configurado."
```

### 2.3 Errores y Problemas

**Tono**: Honesto, tranquilizador, orientado a soluciones

```
✅ "Algo salió mal al cargar tu progreso. No te preocupes, 
   tu XP está guardado. Intenta de nuevo en un momento. 🔄"

❌ "Error 500: Internal Server Error. 
   Por favor, contacte al administrador del sistema."
```

### 2.4 Logros y Celebraciones

**Tono**: Eufórico, específico, generoso

```
✅ "¡INCREÍBLE! 🎉 Acabas de subir al Nivel 5. 
   Has ganado 500 XP y desbloqueado el avatar MUSICALIN. 
   ¡Sigues imparable!"

❌ "Nivel completado. +500 XP. Nuevo avatar disponible."
```

### 2.5 Notificaciones Push

**Tono**: Conciso, motivador, con urgencia sana

```
✅ "🔥 ¡Tu racha de 7 días está en peligro! 
   Completa una lección hoy para mantenerla."

❌ "Recordatorio: No has completado actividades hoy."
```

### 2.6 Contenido Educativo

**Tono**: Curioso, accesible, inspirador

```
✅ "¿Sabías que los modelos de IA aprenden de la misma forma 
   que tú aprendes a montar en bicicleta? 
   A base de intentos, errores y ajustes. 
   Hoy vas a entender exactamente cómo funciona eso."

❌ "En esta unidad se explicarán los fundamentos del 
   aprendizaje automático supervisado."
```

## 3. Escritura en Español

### 3.1 Registro y Tratamiento

- **Tuteo** como predeterminado (tú, te, tu)
- **Ustedeo** solo en contextos empresariales B2B
- **Género inclusivo**: Preferir formas neutras o doblete cuando sea práctico
  - ✅ "usuarios y usuarias" / "el usuario" (genérico aceptable en contextos técnicos)
  - ✅ "tu cuenta", "tu progreso" (sin marca de género)
  - ❌ "tod@s" o "todxs" (no usar)

### 3.2 Puntuación y Estilo

- Puntos suspensivos de expectativa: "¿Listo/a para el desafío...?" ✅
- Emojis: Máximo 1-2 por mensaje, al final o para énfasis, nunca en títulos formales
- Exclamaciones: Con moderación. Demasiadas pierden impacto.
- Preguntas retóricas: Efectivas en onboarding y educación

### 3.3 Vocabulario de Marca

**Términos propios — usar siempre estos:**

| Término LINCE | No usar |
|---|---|
| XP (puntos de experiencia) | puntos, créditos |
| Nivel | etapa, fase |
| Misión | tarea, ejercicio |
| Avatar | personaje, perfil |
| Racha | racha de días ✅ |
| Arsenal IA | catálogo de herramientas |
| Prompt Studio | generador de imágenes |
| Academia | cursos, formación |

## 4. Escritura en Inglés

### 4.1 Tono Global

Mismo tono que en español: empoderador, directo, entusiasta.

```
✅ "You just unlocked a new skill! Keep going — 
   you're on fire 🔥"

❌ "Task completed. New achievement unlocked."
```

### 4.2 Americanismos vs. Britannismos

LINCE usa inglés americano:
- "personalize" (no "personalise")
- "color" (no "colour")
- "organize" (no "organise")

## 5. Escritura en Chino (中文)

### 5.1 Variante

Chino Simplificado (简体中文) para mercado global, chino tradicional para Taiwán/Hong Kong si se requiere localización específica.

### 5.2 Tono

Mantener energía positiva y modernidad. Adaptar expresiones idiomáticas — no traducción literal. El concepto de gamificación es universal.

## 6. Jerarquía de Mensajes

### 6.1 Pirámide de Comunicación

```
                [EMOCIÓN]
               ¡Celebración!
              /             \
         [ACCIÓN]         [BENEFICIO]
       ¿Qué hacer?       ¿Qué ganas?
          /                     \
    [CONTEXTO]             [CONFIANZA]
  ¿Dónde estás?          ¿Por qué funciona?
```

### 6.2 Fórmula para Mensajes Clave

```
[EMOCIÓN POSITIVA] + [HECHO CONCRETO] + [LLAMADA A LA ACCIÓN] + [RECOMPENSA]

Ejemplo:
"¡Excelente trabajo! 🎯 Has completado el 75% del curso de Prompt Engineering. 
Termina el último módulo y consigue tu insignia de Maestro del Prompt."
```

## 7. Qué Hacer y Qué Evitar

### 7.1 ✅ Hacer Siempre

- Celebrar cada logro, por pequeño que sea
- Usar el nombre del usuario cuando es posible
- Dar contexto sobre el valor de lo que está aprendiendo
- Mencionar el XP o recompensa concreta al motivar
- Usar verbos de acción: "descubre", "domina", "conquista", "explora"
- Mantener los mensajes breves en móvil (< 80 caracteres para notificaciones)

### 7.2 ❌ Nunca Hacer

- Usar jerga técnica sin explicación ("API endpoint", "transformer architecture")
- Hablar de fallos de forma negativa sin ofrecer solución
- Presionar con urgencia artificial ("¡Solo quedan 2 plazas!")
- Hacer promesas no verificables ("¡Sé experto en IA en 7 días!")
- Usar lenguaje corporativo frío ("De acuerdo a los términos establecidos...")
- Infantilizar al usuario ("¡Muy bien, pequeño genio!")
- Discriminar por nivel de conocimiento previo

## 8. Ejemplos por Formato

### 8.1 Notificación Push (< 100 chars)

```
🚀 ¡Nuevo curso disponible! "IA para Creativos" te espera. ¿Empezamos?
🔥 Tu racha de 5 días termina hoy. ¡1 lección y la mantienes!
🏆 ¡Subiste al Top 10 semanal! Sigue así y alcanza el #1.
```

### 8.2 Email de Bienvenida (Asunto)

```
✅ "Tu aventura en IA acaba de comenzar ⚡"
✅ "Hola [Nombre], tienes 500 XP esperándote en LINCE"
❌ "Confirmación de registro en la plataforma LINCE"
```

### 8.3 Mensaje de Error

```
✅ Título: "Oops, algo falló"
   Body:   "No pudimos cargar tu progreso ahora mismo. 
            Tu XP y logros están a salvo. 
            Recarga la página para continuar."
   CTA:    "Reintentar"

❌ Título: "Error al procesar la solicitud"
   Body:   "Se ha producido un error en el servidor. 
            Código: 503."
   CTA:    "Aceptar"
```

### 8.4 Descripción de Logro

```
✅ "Maestro del Prompt"
   "Has enviado 50 prompts y has aprendido a refinarlos 
   como un profesional. La IA ya no tiene secretos para ti."

❌ "Prompts completados (50/50)"
   "El usuario ha completado el número requerido de prompts."
```

## 9. Revisión y Aprobación de Textos

### 9.1 Checklist de Revisión

Antes de publicar cualquier texto en LINCE, verificar:

- [ ] ¿Usa el tono adecuado para el contexto?
- [ ] ¿Usa el vocabulario de marca establecido?
- [ ] ¿Celebra o empodera en lugar de regañar?
- [ ] ¿Es conciso? (¿Podría decirse en menos palabras?)
- [ ] ¿Tiene ortografía y gramática correcta en el idioma?
- [ ] ¿Incluye llamada a la acción si la necesita?
- [ ] ¿Mencionas XP, recompensa o beneficio concreto si aplica?
- [ ] ¿Cumple accesibilidad? (texto alternativo, no solo color para significado)
